# exported_pipeline — exported detection pipeline

Auto-generated by the RealSense Cable Video Analyzer. It reproduces the
exact pipeline you tuned in the GUI so you can reuse it in any program.

## Files in this export

- `exported_pipeline.py` — stand-alone script — settings baked in, runs on its own
- `exported_pipeline_lib.py` — **the reusable library** — import this in your code
- `exported_pipeline_config.json` — the tuned settings — the library loads this
- `exported_pipeline.png` — flowchart diagram + settings report
- `exported_pipeline.txt` — the settings report as plain text
- `exported_pipeline_examples/` — 7 ready-to-run example scripts

## Use it in your own program

Copy `exported_pipeline_lib.py` and `exported_pipeline_config.json` next to your code, then:

```python
import cv2
from exported_pipeline_lib import load_pipeline

# 1. load the library with the exported JSON config
pipe = load_pipeline("exported_pipeline_config.json")

# 2. give it an image
img = cv2.imread("photo.jpg")

# 3. get the final mask — exactly what the analyzer shows
mask = pipe.final_mask(img)
cv2.imwrite("mask.png", mask)
```

## Choosing what you get back

`pipe` gives you the output your program needs — pick one:

| You want | Call | Returns |
|---|---|---|
| every mask (like the analyzer) | `pipe.detect(img)` | dict of masks |
| **only the mask** | `pipe.final_mask(img)` | uint8 binary mask |
| **mask + image background** | `pipe.mask_overlay(img)` | BGR image, mask painted on |
| **mask points** (blob centres) | `pipe.mask_points(img)` | `[{x, y, w, h, area}, ...]` |
| **YOLO points** | `pipe.yolo_points(img)` | `[{x, y, name, conf}, ...]` |

All of them also take an optional IR image: `pipe.final_mask(img, ir_img)`.

### `final_mask` — pick which mask

`final_mask(img, key=...)` selects the mask: `"combined"` (default),
`"rgb_mask"`, `"ir_mask"`, or a branch `"up_<branch>"`.

## Notes

- Needs only `opencv-python` + `numpy` (plus `ultralytics` if YOLO is used).
- MOG2 background subtraction and the OVERLAY combine are not
  reproduced (they need video history / are visualisation-only).
- Re-tune in the analyzer and re-export to update the JSON — your
  code does not change, only `exported_pipeline_config.json`.
